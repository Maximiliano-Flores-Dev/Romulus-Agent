Romulus Agent es un agente de IA automejorable con ciclo de aprendizaje cerrado, memoria persistente y soporte multiplataforma. Este proyecto es una bifurcación no oficial de Hermes Agent, reorientada hacia una arquitectura multidispositivo (Android, Linux, Windows, macOS) con delegación de tareas y permisos aplicados a nivel de runtime.

## Qué obtienes

<CardGroup cols={2}>
  <Card title="Núcleo estrecho" icon="microchip">
    Un core mínimo con capacidades en los bordes. Toda extensión ocurre vía plugins, skills o herramientas.
  </Card>

  <Card title="Prompt caching" icon="bolt">
    Conversaciones largas reutilizan prefijos cacheados. El sistema respeta la invariante en cada turno.
  </Card>

  <Card title="Multi-gateway" icon="comments">
    Adaptadores para Telegram, Discord, Slack, WhatsApp, Signal, Matrix y Teams.
  </Card>

  <Card title="Estado persistente" icon="database">
    SQLite en modo WAL con búsqueda FTS5, compresión y reparación automática.
  </Card>

  <Card title="Multidispositivo" icon="mobile-screen">
    Runtimes independientes por plataforma, con delegación segura de tareas entre dispositivos.
  </Card>

  <Card title="Sistema de permisos" icon="shield-halved">
    Niveles `READ_ONLY`, `USER_APPROVAL`, `PRIVILEGED` y `SYSTEM` aplicados por el runtime.
  </Card>
</CardGroup>

## Flujo básico

<Steps>
  <Step title="Instala Romulus">
    Sigue la [guía de instalación](/installation) para tu sistema operativo.
  </Step>
  <Step title="Configura tu proveedor de modelo">
    Elige un proveedor (OpenRouter, OpenAI, local) desde el asistente `hermes setup`.
  </Step>
  <Step title="Ejecuta el agente">
    Lanza `hermes` para entrar al modo interactivo o conecta un gateway.
  </Step>
  <Step title="Extiende con skills">
    Añade skills opcionales, MCP servers o plugins según necesites.
  </Step>
</Steps>
