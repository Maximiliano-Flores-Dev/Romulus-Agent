## Habilitar el extra de mensajería

Los gateways se cargan de forma perezosa. Instala el extra correspondiente:

<CodeGroup>

```bash uv
uv sync --extra messaging
```

```bash pip
pip install -e ".[messaging]"
```

</CodeGroup>

## Ejecutar el asistente

<Steps>
  <Step title="Lanza el asistente">
    ```bash
    hermes gateway setup
    ```
  </Step>
  <Step title="Selecciona la plataforma">
    Elige el gateway que quieres configurar. Puedes activar varios en secuencia.
  </Step>
  <Step title="Introduce los credenciales">
    El asistente pedirá los tokens y URLs necesarios. Se guardan en `.env`.
  </Step>
  <Step title="Verifica la conexión">
    Ejecuta `hermes doctor` para confirmar que el gateway está operativo.
  </Step>
</Steps>

## Ejemplo: Telegram

Para Telegram necesitas un bot creado con `@BotFather` y su token.

<CodeGroup>

```bash .env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234...
```

</CodeGroup>

Después ejecuta:

```bash
hermes gateway setup
```

Selecciona Telegram, pega el token cuando lo pida y confirma. Tu bot quedará escuchando mensajes.

</Info>
