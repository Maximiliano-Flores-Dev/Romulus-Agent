Esta referencia describe los módulos internos del core de Romulus Agent y su responsabilidad. Es una guía conceptual pensada para colaboradores. La API pública aún no está estabilizada.

<Warning>
  La API interna se está reorganizando durante la Fase 2 del roadmap. No dependas todavía de rutas de importación concretas para código externo.
</Warning>

## Módulos principales

<CardGroup cols={2}>
  <Card title="agent/" icon="brain">

  </Card>

  <Card title="hermes_state*.py" icon="database">

  <Card title="gateway/" icon="paper-plane">

  </Card>

  <Card title="skills/" icon="graduation-cap">

  </Card>

  <Card title="providers/" icon="cloud">

  </Card>

  <Card title="plugins/" icon="puzzle-piece">

## Estado (módulos hermes_state\*)

El estado se compone de varios archivos especializados. Cada uno cubre una responsabilidad específica.

| Módulo | Responsabilidad |
| --- | --- |
| `hermes_state.py` | Fachada principal del estado. |
| `hermes_state_schema.py` | Definición del esquema SQLite. |
| `hermes_state_wal.py` | Gestión del modo Write-Ahead Log. |
| `hermes_state_fts.py` | Búsqueda full-text con FTS5. |
| `hermes_state_compression.py` | Compresión de mensajes y trayectorias. |
| `hermes_state_repair.py` | Reparación automática de bases de datos dañadas. |
| `hermes_state_sessions.py` | Ciclo de vida de sesiones. |
| `hermes_state_messages.py` | Persistencia de mensajes. |
| `hermes_state_usage.py` | Métricas de uso y coste. |
| `hermes_state_search.py` | Consultas de búsqueda sobre el estado. |
| `hermes_state_registry.py` | Registro de sesiones y dispositivos. |
| `hermes_state_gateway.py` | Estado específico de gateways. |
| `hermes_state_telegram.py` | Estado auxiliar para Telegram. |
