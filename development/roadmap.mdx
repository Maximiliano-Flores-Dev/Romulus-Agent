## Detalle por fase

<AccordionGroup>
  <Accordion title="Fase 1: Clonar Hermes Agent">
    Análisis de arquitectura, entrypoints, sistema de tools y ciclo de vida del agente. Identificación de componentes reutilizables y preservación del historial upstream cuando fue práctico.
  </Accordion>

  <Accordion title="Fase 2: Estructura de Proyecto">
    Adaptar la estructura para Romulus: separar Agent Core de implementaciones específicas de plataforma. Establecer interfaces comunes para Agents, Models, Tools, Memory, Runtimes, Events y Permissions.
  </Accordion>

  <Accordion title="Fase 3: Branding y Assets">
    Crear la identidad visual (logos, iconos, banners). Reemplazar branding de Hermes y preparar assets para futuras apps móviles y de escritorio.
  </Accordion>

  <Accordion title="Fase 4: Arquitectura Multi-Dispositivo">
    Crear la interfaz `Runtime` común. Separar la funcionalidad específica de plataforma del Agent Core. Implementar adaptadores independientes por sistema operativo.
  </Accordion>

  <Accordion title="Fase 5: Sistema de Capacidades">
    Cada runtime expone qué capacidades soporta (filesystem, shell, notifications, camera, etc.). El agente descubre dinámicamente lo disponible.
  </Accordion>

  <Accordion title="Fase 6: Sistema de Permisos">
    Cuatro niveles: `READ_ONLY`, `USER_APPROVAL`, `PRIVILEGED`, `SYSTEM`. Aplicados en el runtime, nunca solo en el modelo. Políticas configurables por dispositivo.
  </Accordion>

  <Accordion title="Fase 7: Runtime Android">
    Implementación móvil inicial con acceso controlado a archivos, notificaciones, portapapeles, sensores, cámara, micrófono y tareas en segundo plano. Prioridades: bajo consumo de RAM y batería, permisos mínimos, funcionalidad offline.
  </Accordion>

  <Accordion title="Fase 8: Runtime Escritorio (Linux)">
    Ejecución de shell, filesystem, gestión de procesos, portapapeles, notificaciones e integración de modelo local. Preparación de la arquitectura para runtimes posteriores en Windows y macOS.
  </Accordion>

  <Accordion title="Fase 9: Identidad de Dispositivo">
    Cada instalación expone metadata (device ID, nombre, plataforma, versión, capacidades, estado de conexión). El agente reconoce y distingue sus dispositivos.
  </Accordion>

  <Accordion title="Fase 10: Comunicación Multi-Dispositivo">
    Capa Romulus-to-Romulus: descubrimiento, autenticación, emparejamiento, intercambio de mensajes, transmisión de tareas y resultados. Soporte de red local y remota.
  </Accordion>

  <Accordion title="Fase 11: Delegación de Tareas">
    El agente determina qué dispositivo es mejor para cada tarea, la transmite de forma segura y sincroniza el estado. El usuario puede anular las decisiones automáticas.
  </Accordion>
</AccordionGroup>
